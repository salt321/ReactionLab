# 反应实验室

原生 TypeScript 反应速度测试，无第三方依赖。打开 `index.html` 即可使用，浏览器加载已生成的 `dist/main.js`。

修改 `src/main.ts` 后，在此目录运行 `node build.mjs`（需要提供 `node:module.stripTypeScriptTypes` 的 Node.js 版本；本项目使用 Node.js 26.3.0 构建）。不要手工修改 `dist/main.js`。此构建移除类型，不执行 TypeScript 静态类型检查。

- 选择 3–100 次，每次随机等待 3–7 秒后变绿。
- 鼠标左键、触屏按下，或聚焦圆形按钮后按 Space / Enter 记录时间。
- 提前点击清空整轮成绩，并立即重新开始第 1 次；按住键盘不会重复提交。
- 每次开始（包括抢跑后重启）都会显示当前次数和“已开始，请等待变绿”的提示。
- 每次成功后自动进入下一次等待；完成后显示最终平均值。过程中的平均值是已完成次数的平均值。
- 离开窗口或切换标签页使整轮作废；返回后需手动开始。
- 重新开始会清空本轮；测试过程中锁定次数。

状态和成绩仅在内存中保存，不上传、不持久化。计时使用单调时钟 `performance.now()`，随机延迟使用 `Math.random()`；浏览器调度可能使实际等待超过 7 秒。绿色 DOM 更新与时间起点在同一 `requestAnimationFrame` 回调内，无法消除实际屏幕刷新和硬件输入延迟。本工具用于娱乐，不用于医学测量，也不提供对抗脚本或开发者工具篡改的防作弊保证。

`cancelPending` 取消旧计时器和动画帧，代次标识防止过期回调更新状态。浏览器事件循环串行更新状态；没有 Worker、FFI 或共享内存。成绩数组、DOM 节点由 JavaScript 运行时分配并由垃圾回收器释放，无法预先指定内存地址。单次成绩追加和均值更新的应用逻辑为 O(1)，清空记录为 O(n)，总存储 O(n)，n ≤ 100；浏览器布局开销由浏览器决定。

唯一非内部 imports 是构建脚本中的 Node.js 内置 `node:fs/promises`（文件读写）和 `node:module`（移除 TypeScript 类型）。不安装或复制第三方开源代码，不引入框架、网络资源、公共 API、持久化格式或平台通道。
